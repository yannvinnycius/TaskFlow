# TaskFlow – Aplicativo de Gerenciamento de Tarefas

## Sobre o projeto

O TaskFlow é um aplicativo mobile desenvolvido em Flutter e Dart com o objetivo de facilitar a organização de tarefas diárias por meio de um calendário e de uma lista de atividades.

## Funcionalidades

- Tela de login e cadastro demonstrativo.
- Calendário mensal com seleção de datas.
- Cadastro de tarefas para cada dia.
- Marcação de tarefas como concluídas.
- Exclusão de tarefas.
- Organização automática: tarefas pendentes primeiro, seguidas das concluídas, ambas em ordem alfabética.

## Tecnologias utilizadas

- Flutter
- Dart
- Android Studio

## Estrutura e lógica do projeto

O aplicativo utiliza uma classe `Task` para representar as tarefas, armazenando informações como título, data e status de conclusão.

A organização das atividades é realizada por meio de listas e operações de ordenação, permitindo separar tarefas pendentes das concluídas e organizá-las alfabeticamente.

A interface foi construída com widgets do Flutter, incluindo componentes para navegação, calendário, formulários e listas.

## Observações

Esta versão possui autenticação demonstrativa e armazenamento temporário em memória. Os dados cadastrados não são mantidos após o encerramento do aplicativo.
